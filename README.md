1. 在Railway中选择此仓库
2. 添加环境变量：

   - FEISHU_APP_SECRET: FPtiKi98JCm6oVwjdvcSvhsToSClOwx7
3. 点击Deploy

## 功能

- 在飞书中发送任务
- AI自动处理
- 结果推送到飞书

## 使用方法

1. 在飞书中添加机器人为好友
2. 发送消息/任务
3. 等待结果推送
